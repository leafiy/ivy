# Lucide icon resources

These SVG files preserve the original vector geometry of icon assets selected
from Lucide Icons 1.27.0 (markup whitespace is compacted for the app bundle):

https://github.com/lucide-icons/lucide/tree/1.27.0/icons

They are intentionally bundled as SVG rather than redrawn in Ivy. The
corresponding ISC and Feather-derived MIT notices are in
`Resources/Licenses/Lucide.txt`.
